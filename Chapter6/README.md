# 第六章：神经网络学习控制

本例用一个小型神经网络学习高度保持所需的持续前馈作用。仅比较两种控制：常规反馈，以及在同一反馈控制器上加入神经网络学习。网络用反馈修正学习，不读取实际质量差。

## 一键运行

Python：在本章目录执行以下命令，自动完成两组计算、绘图、数据导出和检查。

```bash
python -m pip install -r Python/requirements.txt
python Python/RunMe.py
```

MATLAB：进入 `MATLAB` 目录运行 `RunMe`，无需附加工具箱。两套实现独立计算，不相互调用。输出均在各自的 `results` 目录。

## 模型与网络

- 对象质量1.6 kg，名义质量1.5 kg，重力加速度9.8 m/s²，竖直阻尼1.6 N·s/m。
- 参考高度与初始高度均为3 m，初速度0；反馈修正为6e−5v，推力范围0—24 N。
- 仿真10 s，控制、学习与运动递推周期均为0.01 s。状态用同步显式欧拉更新。
- 输入为参考高度除以3 m，本实验为1；两个tanh隐含单元，一个线性输出，推力尺度1 N。
- 参数顺序为W1、W2、b1、b2、v1、v2、c，初值为[0.3,−0.3,0.2,−0.2,0,0,0]。
- 先计算当前控制作用，再按学习率0.006与当前反馈修正更新参数，下周期使用新参数。全部导数在同一更新前参数点计算。若指令触及推力边界，则暂停本次学习；本例两组均未触及边界。

`forward_and_gradient`（MATLAB中的`network`）展示前向计算与反向传播；`controller`形成指令并更新参数；`simulate`将它们接入运动模型。控制器的接口只有当前高度、速度和网络参数。

## 输出与核对

- `learning_control.pdf/png`：一张图对照高度误差、前馈与反馈修正、总推力，共用一套图例。
- `feedback.csv`、`learning.csv`：每周期状态、控制量与七个参数，字段见首行。
- `summary.json`：末端误差、两路修正、峰值误差与推力范围。

两种实现都运行后，在本章目录执行 `python CheckResults.py`，逐列比较1001个时刻的数据。`sample_results`保存当前算例的结果摘要，`cross_language_validation.json`保存双语言核验结果。

仅用常规反馈时，约0.1633 m的高度偏差产生持续补偿；加入学习后，网络输出接近0.98 N，反馈修正与高度误差逐渐减小。反馈增益始终不变。
