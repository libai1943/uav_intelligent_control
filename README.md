## 使用方法

各章的 `README.md` 说明入口、依赖、参数和输出位置。Python入口为 `RunMe.py`，MATLAB入口为 `RunMe.m`；第2、4—11章按语言放在 `Python`、`MATLAB` 子目录中。两种实现独立计算，不相互调用。

Python通常先安装所在目录的 `requirements.txt`，再运行入口文件。MATLAB切换到对应目录后执行 `RunMe`。第三章使用CasADi/IPOPT，第四章使用CasADi/OSQP；第十一章在没有Optimization Toolbox时使用随附求解器。具体安装要求见各章说明。

第九章默认从随机初始化训练，耗时较长，也提供小预算流程检查。其 `reference_results` 保存教材实验数据和相应模型；历史对手权重是自我对弈算法所需的数据。

第十章生成完整提示词并检查任务输入输出约定；实际语言模型回复由读者送入所选模型后检查。

## 结果核对

运行后按章节说明查看结果；具有双语言比较入口的章节可执行 `CheckResults.py`。验证范围与结果文件见 [运行验证](VALIDATION.md)。仓库按当前章节内容组织，不要求阅读修订日志。
