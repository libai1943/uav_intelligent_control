# 第四章：模型预测控制与固定翼航迹跟踪

本例接续第三章四柱绕障场景的名义航迹，演示**模型预测、滚动优化、反馈校正**如何构成闭环。每周期沿参考建立线性时变预测模型，求解一个凸 QP，仅执行第一段输入，然后用新的仿真状态重新开始计算。

## 一键运行

Python 3.10 或更新版本，在本目录执行：

```bash
python -m pip install -r requirements.txt
python RunMe.py
```

也可从仓库根目录运行 `python Chapter4/RunMe.py`。结果始终写入代码所在目录的 `results/`，与启动目录无关。依赖安装需联网；仿真实验本身不需要网络、商业求解器或 LaTeX。

运行五组实验：

1. `open_loop`：有偏差和扰动，仅执行名义输入。
2. `mpc20`：相同偏差和扰动，预测 20 步。
3. `mpc5`：预测 5 步。
4. `mpc40`：预测 40 步。
5. `ideal20`：无初始偏差、无扰动和模型差别，用来核对离散参考与控制实现。

`python RunMe.py --plots-only` 从已存在的结果重画图，不重新求解。必须先完整运行一次。

图中文字优先使用 Windows 的 Microsoft YaHei，其他系统需安装 Noto Sans CJK SC。若缺少中文字体，数值计算仍可运行，但图中文字可能缺失。

## 模型及符号

- 状态 `x = [x, y, z, V, gamma, chi, phi]`：位置、速率、航迹倾角、航迹方位角、倾侧角；z 向上。
- 输入 `u = [a, omega_gamma, omega_phi]`：速率、航迹倾角、倾侧角的变化率。
- SI 单位，所有角度在计算与 CSV 中均为**弧度**。
- 运动模型与第三章相同，`chi_dot = g*tan(phi)/V`；适用于小爬升角、协调转弯、底层指令跟随较快的航迹层近似，不是完整六自由度飞行动力学。
- 每个区间只使用**一次显式欧拉更新**。没有 RK4，没有区间内积分小步。
- 反馈误差 `e = reference - estimated/predicted state`。
- 输入修正 `delta_u = candidate input - nominal input`。
- 误差模型 `e_next = A*e - B*delta_u + c`，其中 `c` 是保存的参考相对单步欧拉模型的连接残差。

参考文件 `reference/state.csv`、`reference/control.csv` 逐字节取自第三章 `results_kinematic/four_corridor`，36 秒、200 个区间、步长 0.18 秒。参考末端按水平直飞继续外推，保证临近任务记录终点时仍有完整预测窗口；不会让固定翼在终点瞬间停住。

无风模型中，速度分量为 `[V*cos(gamma)*cos(chi), V*cos(gamma)*sin(chi), V*sin(gamma)]`。代价中的速度误差使用这一关系在参考点处的**一阶近似**，否则精确的三角函数平方代价一般不是 QP。汇总中的 `model_velocity_rmse_m_s` 也只比较由该运动模型计算的速度分量，不能把它当作含附加风速的真实地速误差。

## 完整控制计算

`tracking.solve_mpc` 对参考窗口计算解析雅可比，构建带预测误差和输入修正变量的稀疏 QP，调用 OSQP：

- 位置与近似速度的尺度分别为 5 m、2 m/s。
- 输入按允许幅值归一化，修正惩罚权重为 0.05。
- 惩罚的是相对名义输入的修正，不是相邻时刻输入之差。
- 预测起点由当前反馈严格确定。
- 未来输入、速率和角度受范围约束。
- 不设预测窗口末端硬等式，也没有 LQR 终端矩阵。
- 本教学跟踪器不含障碍约束；结果另行计算与柱形禁入区域的间隔。
- 上周期修正序列移位作暖启动，并从新反馈起点重新递推误差。暖启动不是反馈校正的替代品。

`tracking.experiment` 每周期只执行第一个输入，使用非线性对象向前推进，再重新获取反馈。估计值在本例等于仿真状态；没有模拟传感器误差、通信延迟或处理器硬实时调度。

## 扰动与限制

受扰实验初始偏差为 y +5 m、z +3 m、chi +3°。对象的转弯变化率为名义模型的 1.06 倍；8.10 ≤ t < 12.06 秒期间，位置变化率额外增加 `[0,1,0.3]` m/s。这是用于观察反馈的运动学扰动，不模拟完整风—气动力相互作用，控制器不知道这些附加项。

输入限幅为 `[2,0.08,0.4]`，状态范围见 `tracking.py` 顶部常量。程序只在 QP 返回 `solved` 且最大约束违反量不超过 1e-4 时接受解。其他情况抛出异常并停止，不发送任意备用控制值。实际飞控必须另外设计求解超时或不可行时的安全处理。本例没有实机接口。

## 输出与验证

- `*_state.csv`、`*_control.csv`：每组实际状态和已执行输入。
- `*.npz`：绘图用的状态、输入、参考与耗时。
- `*.json`：指标、每次 QP 状态诊断、指定周期预测快照。
- `summary.json`：参数、环境版本、数值检查与各组汇总。
- `figures/*.pdf`、`figures/*.png`：三维图、俯视/高度图、误差、输入、预测更新与线性化图。
- 两个 `*_rows.tex`：教材结果表的数据行。

默认检查解析雅可比与数值差分、参考单步欧拉连接、QP 约束残差、实际输入与状态范围、理想一致性、主实验相对于开环的误差改善。障碍间隔按相邻实际节点间连线到竖直圆柱边界计算，报告而不冒充真实连续系统安全证书。没有一般稳定性证明或实机可执行性保证。

2026-10-21 实测：开环、H=5、H=20、H=40 的位置均方根误差约为 31.45、4.92、1.95、1.83 m。主实验最终位置误差约 0.29 m，最小柱形边界间隔约 27.49 m。四组闭环共求解 800 个 QP，均成功。耗时随硬件、环境负载及依赖版本变化，原始记录见 `sample_results/summary.json`（仓库）或 `results/summary.json`（教材源码包）。
