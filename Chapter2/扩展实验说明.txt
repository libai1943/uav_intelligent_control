第二章 Python 实验

运行
1. 使用 Python 3.10 或更新版本。
2. 在本目录安装依赖：python -m pip install -r requirements.txt
3. 一键计算并出图：python RunMe.py
4. 查看 results 目录。程序采用非交互绘图，不弹出图形窗口。

代码不访问网络，不读取外部数据，不连接任何飞控硬件。
结果总是保存到 RunMe.py 所在目录下的 results，与启动命令的工作目录无关。
重复运行会覆盖本算例同名结果文件；不会删除其他文件。
中文字体优先 Microsoft YaHei；Linux 可安装 Noto Sans CJK SC。
没有中文字体时数值结果仍可生成，但图中文字可能缺字。

模型和接口
  dh/dt = v_z
  dv_z/dt = (T - m*g + d_z)/m
  T = clip(T_cmd, 0, T_max)
  T_cmd = m0*g + Kp*(r-h) + Ki*I - Kd*v_z
  dI/dt = r-h，启用条件积分时按推力饱和方向决定是否暂停。
模型假定近水平、姿态已稳定、总推力瞬时执行、质量恒定、状态反馈准确。
没有水平运动、姿态动力学、空气阻力、电机滞后、噪声、延迟或真实能源模型。
竖直扰动力是带符号的合力示例，不是三维风场或空气动力学模型。
总推力单位N、高度单位m、时间单位s。控制修正可以为负，总推力不为负。

积分
采用经典四阶 Runge--Kutta。控制量在每个 RK4 子阶段重新计算，
模拟连续状态反馈，不是采样保持的数字控制系统。
基本步长0.005 s，自动以0.0025 s重算。扰动在6 s突变，与时间网格对齐；
一个积分区间内使用该区间的扰动力，避免在阶跃前的末端提前施加新外力。
条件积分是分段规则，切换附近的数值差会大于光滑实验，程序报告实际差值。

五组实验
1. p_only、pd：参考3 m，初始2 m；P与PD对比。
2. pd_wind、pid_wind：6 s起施加-2 N外力，比较持续误差。
3. gain2、gain4、gain8：固定Kd=3，改变Kp，比较速度、超调与推力。
4. windup、antiwindup：参考8 m，上限1.25mg，比较两种积分处理。
5. cascade：高度外环P加参考速度前馈，速度内环PI，跟踪平滑参考。
   速度误差的积分状态单位与高度误差的积分状态单位不同。
   参考 r=3+0.6*(1-cos(0.45*t))，参考速度为其导数。

主要输出
  exp1_p_pd、exp2_disturbance、exp3_gains、exp4_windup、exp5_cascade：
    对应曲线，各有矢量PDF和PNG。
  performance.pdf/.png：由gain4的真实数值响应标注过渡性能指标。
  每种配置同名CSV：逐时刻状态和输入，表头含单位。
  results.json：全部参数、库版本、数值核验和指标。
  metrics.csv：阶跃指标汇总。

CSV列
time_s, reference_m, height_m, velocity_m_s, error_m, integral,
raw_thrust_N, thrust_N, disturbance_N, velocity_reference_m_s,
reference_derivative_m_s, integral_derivative
积分状态在前四组为高度误差积分(m*s)，在级联组为速度误差积分(m)。
非级联实验中velocity_reference列记录参考高度的导数，未另设速度内环。

指标口径
上升时间：首次从本次参考阶跃的10%上升到90%所需时间，交点线性插值。
超调：超过参考高度的峰值除以参考阶跃幅度。
调节时间：在有限观测区间内进入±2%阶跃幅度带后不再越界的时刻。
没有满足条件则为null。持续振荡案例不存在稳态极限。
tail_mean_error：最后2 s的平均误差，是有限区间估计，不自动等于理论稳态误差。
扰动实验的阶跃指标按整个观测区间计算，包含扰动后的响应；正文仅用于
展示PD与PID的持续误差，不把其上升时间当作单独的扰动恢复时间。
级联实验报告30 s内高度RMSE和最大绝对误差，不使用阶跃指标。

已执行的核验
全部配置有限数值、推力范围检查、步长减半比较；P与解析余弦解比较；
PD持续扰动的理论稳态误差比较；PID末段误差检查。
本次具体结果以results.json为准。代码内断言针对默认配置，改参数后，
若改变了解析结果或实验目的，需要同步调整相应断言。

修改实验
从main()中的Case列表开始；每个配置独立定义Kp/Ki/Kd、质量、参考、外力、
推力上限等。先只改变一项，再观察高度、速度和推力的变化。

新增的章首示例

前者使用原gain4响应，后者另模拟intro_performance：Kp=4、Kd=2.4、Ki=0，

指标图中上升时间相对于h0与h∞之差，超调相对于h∞，调节带为h∞附近
±2%|h∞-h0|，稳态误差为r-h∞。同时记录相对于参考的超越比例及调节情况。
该示例无法最终进入参考高度±0.02 m带，相应参考调节时间记录为null。
该例还核对闭式解、步长减半和观察末端之后的衰减包络。
