# 第5章教学实验

Python：安装 `Python/requirements.txt` 后运行 `python Python/RunMe.py`。

MATLAB：进入 `MATLAB` 目录运行 `RunMe`，无需附加工具箱。

一个入口完成本章全部对照、绘图、CSV 导出及数值检查，输出位于各自的 `results` 目录。两版独立计算，不相互调用。

参数、模型与更新顺序与教材本章一致。控制指令和对象状态按显式欧拉时序更新，结果图中的曲线由同次运行保存的数据产生。

## 模型、参数与对照

同一49条最大—最小规则，三个论域为-6至6，中心为-6,-4,-2,0,2,4,6。误差尺度5/m，误差变化率尺度10 s/m，输出尺度0.5 N。量化版本半整数向远离零方向取整；连续版本取消输入/输出取整。

模型 m=1.5 kg、g=9.8 m/s²、b=1.5 N s/m，T范围0—22 N，dt=0.01 s，参考3 m，运行30 s。六组数据分别是：初高2.6 m上升、初高2.91 m小偏差、初高3 m且外力-0.2 N，每组包含量化与连续两种算法。检查9厘米死区、连续方案恒力平衡误差1/35 m及单步规则结果。

## 双语言核验

两版运行结束后，在本章目录执行 `python CheckResults.py`。已保存的 `cross_language_validation.json` 给出每组的行数、列数和最大差；`sample_results` 保存两种独立运行的摘要。图形语言可不同，CSV 字段与数值定义一致。
