# 第三章：固定翼无人机开环航迹规划

更新日期：2026-10-19

## 一、运行

Python 3.10+。在本目录执行：

```bash
python -m pip install -r requirements.txt
python RunMe.py
```

测试环境：Windows、Python 3.12.14、CasADi 3.7.2；CasADi自带的IPOPT求解器。
默认顺序运行8组规划实验，再生成前向模拟、梯度下降示例、所有图与表。
结果位于本文件所在目录的results_euler/，不依赖启动时的工作目录。
绘图与独立复核比单次优化调用耗时更长，总流程通常需要数分钟。
可选：python RunMe.py --case four_corridor
已有结果只重画：python RunMe.py --plots-only
绘图需要Microsoft YaHei或Noto Sans CJK SC中文字体，缺失时请先安装。
不需要MATLAB，不连接飞控，不上传数据。

## 二、模型与自由变量

状态：[x,y,h,V,gamma,chi,mu]。
输入：[T,alpha,omega_mu]，分别为推力、迎角、升力倾侧角变化率。
无风、恒定质量、局部惯性系、协调飞行、小迎角近似。
L=0.5*rho*V^2*S*(CL0+CLalpha*alpha)，D采用抛物线阻力极曲线。
载荷因子n=L/(mg)是派生代数量，不作为独立控制量。
T近似切向推力，忽略推力法向分量。mu不是任意姿态下机体欧拉滚转角。
alpha作为规划层输入，假设下层姿态环能实现；不包含舵面/发动机动态。
参数是教学设置，不对应经过辨识或验证的具体实机。

## 三、离散与数值求解

默认36秒、200个控制区间、201个状态配置点，控制区间内零阶保持。
原始决策数7*201+3*200=2007，其中14个起终状态分量固定。
每个控制区间使用8个一阶显式欧拉小步构造连接。
小步中间状态由递推表达式计算，不增加独立优化变量。
没有RK4，没有其他高阶积分方法。
状态与输入全联立优化；不是把所有状态消除的直接单打靶。
CasADi自动微分，抽取18个坐标作中心有限差分校验，误差要求小于3e-5。
IPOPT主要容差1e-8、约束违反容差1e-8、最大迭代700，单次计时只含求解调用。
单次计时不含搜索、初始化、表达式/导数构造、独立复核和绘图，不是实时性保证。
代价是尺度化机动代价，不能当作真实燃油或电能。

## 四、完整初始解

geometry.py使用真正的三维26邻接A*搜索算法，检查连接线段碰撞。
三次样条平滑后重新检查，按弧长近似均匀重采样并分配到固定时间网格。
run_planning.inverse_seed求位置导数，恢复V、gamma、chi，再反解：
F_gamma=m*(V*gamma_dot+g*cos(gamma))；F_chi=m*V*cos(gamma)*chi_dot。
L=hypot(F_gamma,F_chi)；mu=atan2(F_chi,F_gamma)。
alpha=(L/(0.5*rho*V^2*S)-CL0)/CLalpha。
T=m*(V_dot+g*sin(gamma))+D；omega_mu=mu_dot。
补齐全部状态和输入，设置起终状态，截取变量范围并记录运动残差。
初始解可以不完全可行，最终优化与检查负责恢复并核验。

## 五、八组实验

two_straight：双柱直连初始解，直接距离避障。
two_north / two_south：双柱任务两侧绕行初始解，直接距离避障。
two_corridor：双柱，安全走廊。
four_direct / four_corridor：同一四柱任务和初始解，两种避障表达。
five_corridor：五柱安全走廊。
four_grid100：同一四柱走廊任务，100个区间作精度对比。
本版8组均已实际运行，均通过所设数值检查。无全局最优性保证。
额外examples.py复算原著中一维光滑多极值函数和线性时变输入前向模拟。

## 六、间隔与验证

机体包络及额外间隔合计8米。直接距离约束在节点另留3米。
盒体在构造时检查到所有物理柱体的最短距离至少8米；优化节点距盒面再留3米。
速率边界内部缩0.15m/s，三个方向角范围内部缩0.02rad。
默认20个碎片，每个碎片10个控制区间；100区间例每片5个区间。
相邻盒交界点取交集。若种子盒不安全，程序报告失败，不静默接受。
独立复核：从起点连续积分，不在区间端点重置到优化状态；
每区间160个显式欧拉步，再以320步重复，比较重构差异。
检查尺度化离散残差<1e-6，最大节点位置差<3m，步长减半差异<0.05m；
原始状态与盒边界违反量<1e-5，障碍间隔下界>=8m。
间隔下界另外按26m/s和复核采样间隔扣除可能下降量。
这些是教学模型下数值检查，不是严格ODE误差包络或实机安全认证。
accepted同时要求求解器成功与独立检查通过。失败仍保存诊断记录。

## 七、输出

summary.json：参数、环境版本、全部场景结果。
各算例/result.json：成功标志、迭代、耗时、代价、检查值。
各算例/data.npz：状态、输入、完整初始解、走廊、路径、迭代轨迹等。
各算例/state.csv：t,x,y,h,V,gamma,chi,mu（201行，默认）。
各算例/control.csv：t,T,alpha,omega_mu（200行，默认；每行用于随后一个区间）。
CSV采用SI单位和弧度；图片将部分角度转换为度。
PDF为矢量图，PNG供浏览。tables.py按实算结果生成results_euler/tables/中的LaTeX表格片段。
forward_example.csv与gradient_example.json保存两个入门例子的结果。

## 八、修改边界

代码仅用于本章静态环境、固定时间、简化固定翼开环规划教学。
无动态障碍、完整六自由度模型、MPC或实机接口。
更改障碍或参数后，需要重新检查初始路径、时间安排、模型范围与数值误差。
默认案例能求解，不意味着任意任务都可行；求解失败时应阅读诊断记录。


## 输出与运行补充

运行一次只更新当前选择算例的 summary.json；若需八组完整汇总，请运行不带 --case 的默认命令。
--plots-only 需要此前已经计算并保存了所选算例；--no-plots 只求解及核验，不生成图表和入门示例。
表格片段供教材排版使用，含教材定义的 Y 列、tablehead 和 lastline 命令，并非独立的 LaTeX 文档。
仿真和绘图不需要 LaTeX，第三章目录可以独立运行。

数值测试记录和实际使用的依赖版本见仓库根目录 VALIDATION.md。
